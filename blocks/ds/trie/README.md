# Lego Block: `ds/trie`

Trie (prefix tree) structure optimized for string lookup, autocompletion, and prefix checks.

> [!NOTE]
> **AI Agent Context:** Use this block when building search autocompletion suggestions, router matching systems, spell-checking functions, or keyword filtering pools.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ds/trie
```
