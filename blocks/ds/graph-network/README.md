# Lego Block: `ds/graph-network`

An advanced graph network library. Supports directed/undirected representations, shortest path solvers using Dijkstra and A* search, Minimum Spanning Trees (MST) via Kruskal's algorithm (using inline Disjoint Set Union), and Tarjan's Strongly Connected Components (SCC) algorithm.

> [!NOTE]
> **AI Agent Context:** Use this block when you need pathfinding (Dijkstra, A*), spanning tree layouts (Kruskal), or cycle and strongly connected component detections (Tarjan) in directed/undirected graphs.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ds/graph-network
```
