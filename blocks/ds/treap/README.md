# Lego Block: `ds/treap`

A randomized self-balancing binary search tree combining binary search tree properties with heap priorities, supporting insert, delete, search, and split/join operations.

> [!NOTE]
> **AI Agent Context:** Use this block to maintain a dynamic sorted set with O(log n) expected search, insert, and delete operations.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ds/treap
```
