# Lego Block: `ds/binary-search-tree`

Standard Binary Search Tree (BST) class supporting node insertions, searches, deletions, and traversal checks.

> [!NOTE]
> **AI Agent Context:** Use this block when building sorted search lookup trees, range-based indexing structures, or data sorting tree-based pipelines. Import using: import { BinarySearchTree } from './ds/binary-search-tree.js';

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ds/binary-search-tree
```
