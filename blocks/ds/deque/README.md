# Lego Block: `ds/deque`

Double-ended queue with O(1) push and pop at both ends implemented via a doubly linked list.

> [!NOTE]
> **AI Agent Context:** Use this block when you need a queue that supports efficient insertion and removal from both ends, such as sliding window problems, BFS with priorities, or undo/redo stacks.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ds/deque
```
