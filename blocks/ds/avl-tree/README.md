# Lego Block: `ds/avl-tree`

A self-balancing binary search tree supporting guaranteed logarithmic inserts, deletes, and lookups via tree rotations.

> [!NOTE]
> **AI Agent Context:** Use this block to maintain sorted keys with guaranteed O(log N) insertion, search, and deletion.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ds/avl-tree
```
