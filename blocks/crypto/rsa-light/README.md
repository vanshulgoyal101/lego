# Lego Block: `crypto/rsa-light`

Simple RSA cryptographic key pair generator, encrypt/decrypt and message signer helper using basic BigInt modular arithmetic.

> [!NOTE]
> **AI Agent Context:** Use this block to demonstrate RSA asymmetric encryption, key derivation mathematical properties, or basic message signature validation.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add crypto/rsa-light
```
