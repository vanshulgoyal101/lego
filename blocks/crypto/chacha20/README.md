# Lego Block: `crypto/chacha20`

Pure JavaScript implementation of the ChaCha20 symmetric stream cipher (IETF RFC 7539 format) for high-performance encryption and decryption.

> [!NOTE]
> **AI Agent Context:** Use this block for high-speed symmetric encryption/decryption of buffers or byte arrays using a 256-bit key and a 96-bit nonce.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add crypto/chacha20
```
