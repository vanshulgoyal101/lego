# Lego Block: `crypto/rc4`

RC4 stream cipher implementing the Key-Scheduling Algorithm (KSA) and Pseudo-Random Generation Algorithm (PRGA) for encryption and decryption.

> [!NOTE]
> **AI Agent Context:** Use this block to encrypt or decrypt byte streams or strings using the RC4 symmetric stream cipher algorithm.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add crypto/rc4
```
