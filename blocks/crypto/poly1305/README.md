# Lego Block: `crypto/poly1305`

Pure JavaScript implementation of the Poly1305 one-time authenticator algorithm utilizing 130-bit BigInt finite field arithmetic.

> [!NOTE]
> **AI Agent Context:** Use this block to generate cryptographic message authentication tags using a 32-byte key.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add crypto/poly1305
```
