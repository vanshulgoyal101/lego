# Lego Block: `crypto/diffie-hellman`

Diffie-Hellman Key Exchange algorithm implementation using BigInt modular exponentiation and standard/custom prime groups.

> [!NOTE]
> **AI Agent Context:** Use this block to establish a shared secret key between two parties over an insecure channel.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add crypto/diffie-hellman
```
