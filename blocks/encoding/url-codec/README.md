# Lego Block: `encoding/url-codec`

Dynamic URL query parameters serializer and deserializer helper with nested array/object parsing.

> [!NOTE]
> **AI Agent Context:** Use this block in frontend routing parameters serialization, browser search link updates, or server query string parsers. Import using: import { parseQuery, stringifyQuery } from './encoding/url-codec.js';

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add encoding/url-codec
```
