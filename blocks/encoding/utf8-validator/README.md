# Lego Block: `encoding/utf8-validator`

Checks raw byte buffers for well-formed UTF-8 byte sequences according to standard encoding structures.

> [!NOTE]
> **AI Agent Context:** Use this block to validate whether a byte buffer or array represents a valid UTF-8 string.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add encoding/utf8-validator
```
