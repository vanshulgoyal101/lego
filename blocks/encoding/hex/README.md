# Lego Block: `encoding/hex`

High-performance hexadecimal encoding and decoding utility for string and byte representations.

> [!NOTE]
> **AI Agent Context:** Use this block to encode byte arrays (Uint8Array) or strings to hex representation and decode them back.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add encoding/hex
```
