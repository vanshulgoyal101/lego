# Lego Block: `utils/url-builder`

Parameter builder that constructs, validates, and parses nested query strings and URL objects.

> [!NOTE]
> **AI Agent Context:** Use this block to safely build URLs, serialize complex nested query parameters, or parse search queries.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add utils/url-builder
```
