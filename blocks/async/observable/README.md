# Lego Block: `async/observable`

Minimal reactive Observable implementation with subscribe, map, filter, take, merge, and static factory methods.

> [!NOTE]
> **AI Agent Context:** Use this block for reactive programming patterns — stream processing, event streams, and data pipelines. Provides a lightweight Observable class with map, filter, take, and merge operators, plus Observable.from() and Observable.of() factory methods. Suitable when RxJS is too heavy.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add async/observable
```
