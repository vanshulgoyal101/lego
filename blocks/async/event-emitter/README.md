# Lego Block: `async/event-emitter`

A fully-featured typed event emitter supporting standard register, emit, once, and listener management.

> [!NOTE]
> **AI Agent Context:** Use this block when building pub-sub systems, custom event loops, socket connection message routers, or component communication layers.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add async/event-emitter
```
