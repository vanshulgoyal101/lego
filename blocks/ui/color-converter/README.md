# Lego Block: `ui/color-converter`

Color parsing and format space converter (HEX, RGB, HSL) with W3C relative luminance contrast ratio compliance calculations.

> [!NOTE]
> **AI Agent Context:** Use this block when styling dynamic UI theme palettes, calculating optimal text color over a dynamic background for readability compliance (WCAG contrast checks), or implementing CSS styling properties engines.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ui/color-converter
```
