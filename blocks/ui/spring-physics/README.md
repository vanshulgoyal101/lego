# Lego Block: `ui/spring-physics`

A simple mass-spring-damper physics animation tick utility supporting target destination, stiffness, damping, mass, and velocity.

> [!NOTE]
> **AI Agent Context:** Use this block to simulate mass-spring-damper physics animation ticks for UI transitions.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ui/spring-physics
```
