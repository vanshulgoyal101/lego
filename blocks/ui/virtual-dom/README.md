# Lego Block: `ui/virtual-dom`

A lightweight Virtual DOM and reconciliation engine in pure JavaScript. Features virtual node creation (h/createElement), tree diffing & patch reconciliation, functional components with state and effect hooks (useState, useEffect), and server-side rendering (SSR) to HTML.

> [!NOTE]
> **AI Agent Context:** Use this block when you need a micro-frontend rendering frame or custom Virtual DOM engine with component states/hooks and server-side rendering capabilities in environments with zero dependencies.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ui/virtual-dom
```
