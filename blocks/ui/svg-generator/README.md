# Lego Block: `ui/svg-generator`

Programmatically constructs SVG shapes (rect, circle, line, polygon, path) and attributes, and exports to SVG XML string format.

> [!NOTE]
> **AI Agent Context:** Use this block to generate SVG markup dynamically using standard shapes and properties.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ui/svg-generator
```
