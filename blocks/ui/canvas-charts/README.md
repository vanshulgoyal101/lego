# Lego Block: `ui/canvas-charts`

Programmatic bar, line, and pie chart renderer for HTML Canvas element context based on input options (data, dimensions, colors, labels).

> [!NOTE]
> **AI Agent Context:** Use this block to draw responsive bar, line, and pie charts programmatically onto HTML Canvas 2D contexts.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ui/canvas-charts
```
