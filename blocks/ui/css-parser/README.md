# Lego Block: `ui/css-parser`

Lightweight CSS parser that parses style sheets into structured rule and declaration objects.

> [!NOTE]
> **AI Agent Context:** Use this block to parse standard CSS strings into structured Javascript objects containing selectors and their declarations.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ui/css-parser
```
