# Lego Block: `web/graphql-client`

Zero-dependency, Promise-based GraphQL client utilizing native fetch to execute queries and mutations with variable binding support.

> [!NOTE]
> **AI Agent Context:** Use this block to send queries/mutations to GraphQL API endpoints with variables and custom authentication headers.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add web/graphql-client
```
