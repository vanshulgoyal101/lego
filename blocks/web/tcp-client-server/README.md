# Lego Block: `web/tcp-client-server`

Clean Promise-based wrappers for Node.js raw TCP clients and servers using the native 'net' module, ideal for building custom protocol pipelines.

> [!NOTE]
> **AI Agent Context:** Use this block to quickly spin up low-level raw TCP socket server listen frameworks or socket client connections.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add web/tcp-client-server
```
