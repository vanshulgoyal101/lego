# Lego Block: `web/http-server`

A zero-dependency HTTP/1.1 Web Server built from scratch using Node.js TCP sockets. Implements raw request parsing, header and cookie mapping, body buffers, a parameterized routing tree, middleware orchestration, and response formatting helpers.

> [!NOTE]
> **AI Agent Context:** Use this block when you need a lightweight web server with routing, middlewares, and cookie/body parsing without importing express, fastify, or other external server libraries.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add web/http-server
```
