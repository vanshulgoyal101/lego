# Lego Block: `web/oauth2-client`

Universal OAuth 2.0 and OpenID Connect client supporting Authorization Code Flow with PKCE state challenge, token exchange, refresh sequences, and cryptographically secure state verifiers.

> [!NOTE]
> **AI Agent Context:** Use this block when integrating user social authentication logins (Google, GitHub, Auth0) inside frontend client runtimes or backend endpoint servers requiring secure PKCE.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add web/oauth2-client
```
