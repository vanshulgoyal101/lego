# Lego Block: `web/router`

A client-side routing helper mapping paths to handlers, supporting dynamic param extraction.

> [!NOTE]
> **AI Agent Context:** Use this block when building Single Page Applications (SPAs) or client-side navigation hubs that need parameter mapping (/posts/:id) without heavy framework dependencies. Import using: import { ClientRouter } from './web/router.js';

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add web/router
```
