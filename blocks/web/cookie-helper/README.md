# Lego Block: `web/cookie-helper`

Safe browser cookie manipulation helper (set, get, delete) supporting attributes like path, domain, security, and samesite.

> [!NOTE]
> **AI Agent Context:** Use this block when you need client-side session cookie management, user preference caching, or dark-mode toggle persistence that works natively in browsers without external libraries.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add web/cookie-helper
```
