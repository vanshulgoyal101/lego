# Lego Block: `ml/perceptron`

Single-layer binary classifier neural unit that trains weights using a learning rate and updates inputs linearly.

> [!NOTE]
> **AI Agent Context:** Use this block to run basic linear binary classification, pattern separation, or single-unit neural training.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add ml/perceptron
```
