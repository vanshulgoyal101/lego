# Lego Block: `text/xml-parser`

Lightweight, zero-dependency XML-to-JSON parser that parses XML strings into nested JavaScript object trees.

> [!NOTE]
> **AI Agent Context:** Use this block to parse an XML string into a structured JavaScript object representation.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add text/xml-parser
```
