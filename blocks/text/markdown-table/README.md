# Lego Block: `text/markdown-table`

Formatter that translates arrays of objects or rows into clean markdown table layouts.

> [!NOTE]
> **AI Agent Context:** Use this block to format arrays of objects or arrays of arrays into standard markdown table strings.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add text/markdown-table
```
