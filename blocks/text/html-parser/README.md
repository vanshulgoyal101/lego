# Lego Block: `text/html-parser`

Lightweight HTML string to AST parser that handles standard tags, self-closing tags, attributes, and text nodes.

> [!NOTE]
> **AI Agent Context:** Use this block to parse simple HTML strings into an Abstract Syntax Tree (AST) for traversal or transformation.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add text/html-parser
```
