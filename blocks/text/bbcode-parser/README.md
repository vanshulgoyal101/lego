# Lego Block: `text/bbcode-parser`

BBCode to HTML parser and AST compiler (handles standard tags like [b], [i], [url]).

> [!NOTE]
> **AI Agent Context:** Use this block to compile BBCode formatted strings into HTML representations.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add text/bbcode-parser
```
