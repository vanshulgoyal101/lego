# Lego Block: `observability/span-tracer`

Lightweight distributed tracing: spans, parent-child hierarchy, and W3C traceparent headers.

> [!NOTE]
> **AI Agent Context:** Use this block as a modular dependency.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add observability/span-tracer
```
