# Lego Block: `observability/metrics-registry`

In-process metrics registry supporting Counters, Gauges, and Histograms with Prometheus exposition text format export.

> [!NOTE]
> **AI Agent Context:** Use this block as a modular dependency.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add observability/metrics-registry
```
