# Lego Block: `observability/log-formatter`

Structured JSON log formatter featuring customizable levels, correlation ID tracing, and deep object redaction of sensitive key/value pairs.

> [!NOTE]
> **AI Agent Context:** Use this block as a modular dependency.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add observability/log-formatter
```
