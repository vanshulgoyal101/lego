# Lego Block: `observability/health-check`

HTTP health/readiness/liveness checker with support for concurrent checks, timeouts, and standard HTTP server handlers.

> [!NOTE]
> **AI Agent Context:** Use this block as a modular dependency.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add observability/health-check
```
