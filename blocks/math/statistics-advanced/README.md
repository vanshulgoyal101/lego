# Lego Block: `math/statistics-advanced`

Implements advanced statistical analyses including ANOVA (Analysis of Variance) and t-tests for hypothesis testing.

> [!NOTE]
> **AI Agent Context:** Use this block to run statistical hypothesis testing like t-test and one-way ANOVA calculations.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/statistics-advanced
```
