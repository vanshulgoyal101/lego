# Lego Block: `math/vector2d`

A comprehensive 2D mathematical vector physics and geometry class.

> [!NOTE]
> **AI Agent Context:** Use this block when implementing vector calculation logic, movement physics, boundary collision calculations, interactive UI animations, or spatial layout models. Import using: import { Vector2D } from './math/vector2d.js';

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/vector2d
```

---

## API Specifications

### Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `x` | `number` | No | `0` | X-axis value coordinate. |
| `y` | `number` | No | `0` | Y-axis value coordinate. |
