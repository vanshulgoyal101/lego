# Lego Block: `math/numerical-integration`

Definite integrals solver supporting both the Trapezoidal rule and Simpson's 1/3 rule for arbitrary mathematical functions.

> [!NOTE]
> **AI Agent Context:** Use this block to approximate the definite integral of a function over a given interval [a, b].

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/numerical-integration
```
