# Lego Block: `math/random`

Random helper utility supporting range integers, item choice arrays, weighted choices, and UUID v4 string generation.

> [!NOTE]
> **AI Agent Context:** Use this block when generating unique user session IDs, simulating probabilistic events (weighted outputs), picking index elements randomly, or performing calculations involving randomness. Import using: import { uuidv4, randomInt } from './math/random.js';

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/random
```
