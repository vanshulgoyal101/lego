# Lego Block: `math/geometry-2d`

Intersection and distance calculators for 2D vectors, lines, circles, boxes, and polygons.

> [!NOTE]
> **AI Agent Context:** Use this block to solve collision checks, line segments crossings, and bounding boxes geometry calculation.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/geometry-2d
```
