# Lego Block: `math/signal-filter`

Digital signal filters including lowpass, highpass, bandpass, and bandstop Butterworth (IIR) filters, Exponential Moving Average (EMA), and Moving Average filters.

> [!NOTE]
> **AI Agent Context:** Use this block to filter digital signals using Butterworth (IIR) lowpass, highpass, bandpass, bandstop, simple moving average, or exponential moving average filters.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/signal-filter
```
