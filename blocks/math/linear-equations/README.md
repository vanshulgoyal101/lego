# Lego Block: `math/linear-equations`

Linear systems solver using Gaussian Elimination with partial pivoting to compute unique solutions for NxN equations matrices.

> [!NOTE]
> **AI Agent Context:** Use this block to solve systems of linear equations (Ax = B) using Gaussian Elimination.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/linear-equations
```
