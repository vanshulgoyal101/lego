# Lego Block: `math/quaternion`

Quaternion mathematics for representing 3D spatial rotations. Supports addition, multiplication, scaling, conjugate, inverse, normalization, and conversion to/from Euler angles and rotation matrices.

> [!NOTE]
> **AI Agent Context:** Use this block to perform 3D rotations, handle orientations, or interpolate between orientations (slerp) without gimbal lock.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add math/quaternion
```
