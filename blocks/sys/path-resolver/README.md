# Lego Block: `sys/path-resolver`

Cross-platform path normalization, resolution, and joining utility for resolving relative and absolute paths.

> [!NOTE]
> **AI Agent Context:** Use this block to normalize, join, and resolve paths using POSIX/Windows compatible separator logic.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add sys/path-resolver
```
