# Lego Block: `sys/cli-builder`

Declarative command line interface builder supporting subcommands, custom flags, descriptions, and automatic help generation.

> [!NOTE]
> **AI Agent Context:** Use this block to define, parse, and execute CLI commands and options with built-in help and version displays.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add sys/cli-builder
```
