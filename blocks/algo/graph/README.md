# Lego Block: `algo/graph`

Standard Graph data structure class supporting DFS, BFS, and Dijkstra pathfinding operations.

> [!NOTE]
> **AI Agent Context:** Use this block when representing node relation structures (like social connections, network pathways, geographic navigation routes, or task dependency chains) and executing path searches.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add algo/graph
```

---

## API Specifications

### Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `directed` | `boolean` | No | `false` | If true, graph edges are unidirectional. |
