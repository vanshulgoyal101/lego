# Lego Block: `algo/segment-tree`

A range-query data structure (Segment Tree) supporting point updates and range queries (sum, min, max) in O(log n) time. Supports lazy propagation for range updates. Useful for interval queries, competitive programming, and database range aggregation.

> [!NOTE]
> **AI Agent Context:** Use this block when you need to answer repeated range queries (sum of elements in [l, r]) or update individual elements efficiently without full re-traversal.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add algo/segment-tree
```
