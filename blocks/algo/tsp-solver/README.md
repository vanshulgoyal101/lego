# Lego Block: `algo/tsp-solver`

Backtracking Travelling Salesperson Problem (TSP) shortest tour path solver.

> [!NOTE]
> **AI Agent Context:** Use this block to find the exact shortest path visiting all nodes/cities in a graph and returning to the start.

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add algo/tsp-solver
```
