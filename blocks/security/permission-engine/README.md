# Lego Block: `security/permission-engine`

RBAC/ABAC permission evaluator with role hierarchies.

> [!NOTE]
> **AI Agent Context:** Use this block to evaluate access permissions using combined Role-Based (RBAC) with hierarchy inheritance and Attribute-Based (ABAC) dynamic condition checking. Import using: import { PermissionEngine } from './security/permission-engine/index.js';

---

## Installation

To copy this block directly into your project codebase, run the following CLI command:
```bash
npx lego-cli add security/permission-engine
```
