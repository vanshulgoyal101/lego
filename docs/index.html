Select a modular block from the sidebar to inspect parameters, view production-grade code, read runtime compatibility details, and copy directly into your codebase.

CLI Usage

You can discover and add blocks using the repository CLI helper:

# List available blocks
node bin/cli.js list

            # Search blocks
            node bin/cli.js search websocket

            # View a block's metadata
            node bin/cli.js view web/fetch-retry

# Copy block to target directory
node bin/cli.js add web/fetch-retry --dest ./src/utils

# Copy block with README
node bin/cli.js add web/fetch-retry --dest ./src/utils --with-readme

# Validate registry health
node bin/cli.js doctor
